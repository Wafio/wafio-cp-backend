# Wafio v1.8.1 release notes

Status: released 2026-10-16 from `main` (tag `v1.8.1`). Previous release: [v1.8.0](v1.8.0.md) (2026-10-16).

A patch release on top of v1.8.0. No database migration (schema stays at 000111), no agent protocol
change and no eBPF change. Upgrade the control plane, the WAF agent and the host agent (each carries
a fix); the installer does this in the usual way and needs no change.

## Fixed

- **Upgrades warned "Security data download incomplete" when the MalwareBazaar key is saved in the
  dashboard.** `wafio fetch-data` read the auth key only from `WAFIO_MALWARE_AUTH_KEY`, so on a
  control plane whose key was saved under Administration › Security data the malware download
  failed (the previous corpus was kept) and the installer reported the whole download as
  incomplete. The command now reads the key the control plane uses: the environment first, then the
  saved key (decrypted with `totp.enc_key`, read with the database settings of `config.yaml`). It
  names the source and never prints the key. Without any key, a `--profile` run skips the malware
  download, says so and keeps the current corpus (exit 0); `--only malware` still reports the
  missing key.
- **Every agent-only WAF install would have shown the same warning.** WAF and host agents receive
  the malware corpus from the control plane (the key never leaves it), yet their `fetch-data`
  profiles tried to download it themselves. A `--profile` run without a key in the environment now
  skips it with a note.
- **The WAF agent logged "ready timeout — no bundle yet" after it had applied a bundle.** The
  20-second start fallback logged and signalled readiness even when the first bundle (live or
  cached) had already done so; it now does nothing in that case.
