# Wafio v2.2.1 release notes

Released on 25 November 2026. This file lists what v2.2.1 changes for an operator, for the dashboard and for a client of the HTTP API.
It covers the control plane, the dashboard and the WAF agent. The host agent stays at v2.2.0; its bundle is signed again for
v2.2.1.

## Upgrade

- There is no migration. Upgrade the control plane, then the WAF agents.
- The agent-wide IP jail of the WAF agent is off by default now: `--jail-threshold` defaults to 0 (it was 5). In v2.2.0 that jail
  dropped a client at the host firewall, on every port, after 5 blocks in a minute, for an hour, for every application served in
  Gateway mode. To keep that behaviour, set `--jail-threshold 5` in a drop-in of the WAF agent unit, or choose the server
  firewall in the block policy of the application (see "New").
- A v2.2.0 WAF agent ignores `block_policy.target` and keeps its agent-wide jail until it is upgraded.

## New

### Where a block policy block applies

- The block policy of a project or an application (WAF policy, Rate limit) has a new choice, "Where the block applies":
  - "WAFio only", the default: the client gets 403 from WAFio on that application until the block ends. Its other traffic to
    the server, SSH included, is untouched.
  - "WAFio and the server firewall": when the block policy blocks a client, the WAF agent also asks the host agent to drop every
    packet from the client's address, on every port, SSH included, for the time left in the block.
- The setting works in both modes. In Gateway mode the address is the TCP peer. Behind a web server on the same host (a forwarded
  address that arrives from loopback) the forwarded address is dropped too. Behind a CDN or a load balancer on another machine
  only the WAFio block applies, because the packets come from the CDN's addresses.
- Addresses the agent never jails stay exempt: loopback, the host's own addresses, the control plane and trusted proxies.
- API: `block_policy.target` in `rules_json`, `"waf"` (default, also when missing) or `"kernel"`. Any other value is refused.

## Known issues

- Unblock in the Block window tab ends the WAFio block only. A drop at the server firewall ends when the block time is over, or
  when the host agent restarts.
- There is no list of addresses that a block policy never blocks yet. Do not test attacks from an address you use to manage the
  server while the server firewall is chosen.
