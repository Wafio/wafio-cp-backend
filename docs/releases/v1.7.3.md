# Wafio v1.7.3 release notes

Status: released 2026-10-15 from `main` (tag `v1.7.3`). Previous release: [v1.7.2](v1.7.2.md) (2026-10-11).

A patch release on top of v1.7.2. No database migration, no agent protocol change and no eBPF change.
Upgrade the control plane (the dashboard ships with it); the WAF and host agents have no change and
may stay on v1.7.2.

## Fixed

- **The Decisions table of an application showed no country for stored decisions.** The country is
  resolved and stored when a decision is ingested, but the app and project decision lists
  (`GET /api/projects/:id/apps/:appId/waf/decisions` and the project list) did not read
  `country_code` back, so the Country column stayed "—" unless the row arrived on the live stream.
- **Left and right edges did not line up across the dashboard.**
  - The first tab label sat 12 px (8 px for small tabs) inside the content edge on the application,
    Firewall, Runtime Security, Project Settings and Audit Log pages. Tabs now start on the content
    edge and the active underline spans the label.
  - KPI strips (Overview, Monitoring, WAF Agents, Firewall, Runtime Security) started 4 px inside
    the content edge.
  - The search box of Custom Rules stopped 24 px short of the right edge when the toolbar wrapped.
  - The header logo moved 20 px to the left when a project or Administration opened. It now stays
    on the page gutter on every page, and the sidebar text (project block, group titles, menu
    items) starts on the same line.

## Changed

- **Live updates on the Decisions tab, on by default.** The tab no longer receives every decision
  of the project. With `?app_id=` the decision stream
  (`GET /api/projects/:id/agent-decisions/stream`) carries only a `stored` signal, at most once per
  2 seconds, after the control plane has written decisions of that application. The tab then reads
  only the rows newer than the ones it shows, with the active filters applied by the server.
  - While nothing happens, an open tab costs no query. Under heavy traffic or an attack, it costs
    one small indexed query per 2 seconds, however many requests the WAF sees.
  - The stream form without `app_id` is unchanged.
  - Stored-decision streams count toward the existing stream limits (64 per project, 512 in all,
    8 per user per project, 32 per user).
  - An `app_id` that is not an application of the project gets 404.
- The full reload of the Decisions tab runs every 120 seconds while live updates are connected
  (30 seconds otherwise), to refresh the total.
