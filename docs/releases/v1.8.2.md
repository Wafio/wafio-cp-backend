# Wafio v1.8.2 release notes

Status: released 2026-10-16 from `main` (tag `v1.8.2`). Previous release: [v1.8.1](v1.8.1.md) (2026-10-16).

A dashboard patch on top of v1.8.1. No database migration, no agent protocol change and no eBPF
change. Upgrade the control plane (the dashboard ships with it); the WAF and host agents have no
change and may stay on v1.8.1.

## Fixed

- **Custom Rules asked about unsaved changes on every filter tab.** After the rule dialog had been
  opened once — to create, edit or copy a rule, even when the rule was saved — clicking a filter tab
  (All, Enabled, Disabled, Match & Act, Engine Tuning, Script) showed "The custom rule has unsaved
  changes. Leave without saving?". The dialog's unsaved-changes tracker kept the last form as its
  baseline after closing, so the page stayed "dirty" and every navigation, including the URL update
  of a tab click, asked. The tracker now resets when the dialog closes; unsaved edits in an open
  dialog are still guarded.
