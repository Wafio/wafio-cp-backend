# Wafio v1.7.1 release notes

Status: released 2026-10-11 from `main` (tag `v1.7.1`). Previous release: [v1.7.0](v1.7.0.md) (2026-10-10).

A patch release on top of v1.7.0. No database migration, no agent protocol change and no eBPF change:
the agents and eBPF objects behave as in v1.7.0.

## Fixed

- **Dashboard, Administration sidebar.** The sidebar used the class name of the header menu, so the
  header's styles applied to it: the active item lost its bottom padding and its text moved down by about
  4 px on every click, and at widths of 768 px or less the menu was hidden. The sidebar now has its own
  class.
- **Dashboard, Administration tables.** Cells in the Users, Invitations, Security Data and Global Audit
  Log tables are centred vertically, so text lines up with the badges and buttons of the same row.
  "(you)" next to your own email has a gap, and Delete on your own account is a disabled button in the
  same style as Edit and Reset password.
- **Dashboard, application Decisions table.** Country and Categories (the attack type: SQLi, XSS,
  Bot …) are shown by default again, between Client IP and Score; the default was 6 of 12 columns and
  hid both. Column choices saved before this release are reset once (new storage name), since they
  predate the new defaults. Rows that arrive through Live tail now carry the country too: the live
  stream resolves it with the dashboard's GeoIP data (before, a live row showed "—" until the page
  reloaded the stored decision).
- **Installer (`install.sh`).** The systemd units it writes now match the templates in `deploy/systemd`:
  - the WAF agent unit gets `StateDirectory=wafio-waf-agent`, so the bundle cache works and a
    restart while the control plane is unreachable still serves the protected apps (before:
    "no state directory ... bundle cache disabled");
  - the host agent unit gets `RuntimeDirectory=wafio` for the local API token.
  The host agent menu entry now reads "Linux 5.10+".

## Upgrade

Run the installer again (`curl -fsSL https://wafio.cloud/install.sh | sudo bash`); it detects the
existing install and upgrades in place. The installer rewrites the agent units, so the bundle cache
starts working after this upgrade without manual changes.

## Known limitations

As in [v1.7.0](v1.7.0.md#known-limitations). The Members page under Project Settings still shows table
text a few pixels above the row's buttons; the fix belongs in the shared table component and is planned.
The malware hash feed (`wafio fetch-data --only malware`) needs `WAFIO_MALWARE_AUTH_KEY` (abuse.ch);
without it the previous malware database is kept.
