# Wafio v1.8.0 release notes

Status: released 2026-10-16 from `main` (tag `v1.8.0`). Previous release: [v1.7.3](v1.7.3.md) (2026-10-15).

A feature release. It adds the host fleet view and multi-host apply, one-command host
enrollment, password recovery, email (SMTP) settings in Administration, a false-positive rate
for WAF decisions, and the fixes of a full bug hunt (functional, security and runtime noise).

## Upgrade

Order: control plane (it runs migrations 000101–000111) → WAF agents → host agents together
with the new eBPF objects. The installer does this in the usual way:

```
curl -fsSL https://wafio.cloud/install.sh -o wafio-install.sh && sudo bash wafio-install.sh controlplane
```

- **Migrations 000101–000111.** 000101 makes trace policy ids unique per agent, 000102 makes WAF bundle generations one global sequence (stuck
  agents recover), 000103 gives every host desired state a new revision (one re-push), 000104 adds a
  foreign key on `correlation_rules.project_id`, 000105 a unique host-key lookup id, 000106
  calibrates built-in runtime rules, 000107 adds password reset tokens, 000108 host enrollment
  columns, 000109 a partial index for the feedback summary (built one chunk at a time on
  TimescaleDB after `migrate up`), 000110 `system_audit.metadata`, 000111 calibrates two more
  built-in runtime rules (systemd unit sandbox mounts, PID 1 environment reads). The control plane
  must not run on a schema older than 000111.
- **The installer keeps `config.yaml` on upgrade.** Earlier installers regenerated the file and
  kept only the JWT secret, database credentials and TOTP key; every other setting was lost on
  each upgrade. Upgrades now keep the file as it is (backup next to it) and only fill a missing
  `totp.enc_key`. Installs upgraded with an earlier installer may have lost settings — check
  `config.yaml.bak.*`.
- **Behind a reverse proxy, set `server.trusted_proxies`.** The control plane now resolves the
  client IP like the WAF does. Without the setting every request behind nginx counts as
  the proxy's address, so per-IP limits (login, password recovery, enrollment) are shared by all
  users and the audit log records the proxy. Same host as nginx:

  ```yaml
  server:
    trusted_proxies: ["127.0.0.1", "::1"]   # WAFIO_SERVER_TRUSTED_PROXIES
    proxy_header: X-Forwarded-For           # or X-Real-IP; WAFIO_SERVER_PROXY_HEADER
  ```
  Restart the control plane after changing it.
- **Agents.** Upgrade both. The host agent needs the eBPF objects of this release (trace program
  changed). A WAF agent older than this release receives bundles without the new JWT/GraphQL
  path-override keys (they would make it refuse the whole bundle); upgrade agents before relying
  on those overrides.
- **Dashboard assets.** HTML is served `no-cache` and hashed assets `immutable`; a missing asset
  is 404. The installer keeps the previous build's chunks for 30 days and the page reloads once
  if a cached page cannot load its chunks, so open tabs no longer go blank after an upgrade.

## Added

- **Host fleet** (Hosts page): protection per host (firewall, runtime, incidents, agent version),
  KPIs and filters, selection, bulk label edit, and one-shot apply to many hosts — add or remove
  firewall rules, copy runtime policies and detection rules — with dry run, typed confirmation,
  per-host results and the lockout guard on every host. A host switcher on Firewall and Runtime
  Security remembers the last host.
- **One-command host enrollment.** The installer creates the agent's key on the host, sends a
  CSR with the Host Key and receives a client certificate bound to that host and agent
  (`POST /api/internal/host-enroll`). The Host Key is piped to the installer, the CA is pinned,
  enrollment is open 24 h after a host is created or its key rotated, at most 4 enrolled agents per
  host, certificates last 365 days. Revoking or deleting a host revokes its enrolled credentials
  and closes their streams. The manual credential path still works.
- **Password recovery by email** (`/forgot-password`, `/reset-password`): the same answer whether
  or not the account exists, a single-use 30-minute token in the URL fragment, all sessions
  revoked after a reset, 2FA unchanged.
- **Administration › Email (SMTP)**: mail server, sender and dashboard base URL from the dashboard,
  applied without a restart; the password is stored encrypted and never shown; a test email; values
  set in `config.yaml`/environment win and show read-only. Changing the host or username clears the
  saved password unless a new one is given.
- **Detection quality**: false-positive rate of reviewed blocks per project and app, by app,
  category and detection method (`GET /api/projects/:id/waf/feedback/summary`), plus "How decisions
  were made" and HTTP methods panels on the Overview.
- JWT and GraphQL detectors are configurable (off, base score) project-wide, per path and in
  tuning `skip_semantic`, and carry CWE/MITRE taxonomy.
- Correlation rules accept `addr`, `dest_scope`, `exe_verified` and `not_in`; stored rules are
  loaded at startup.

## Fixed

- **Dashboard went blank after an upgrade** until a hard reload (cached `index.html`, missing chunks
  answered with HTML).
- **WAF counts**: `log` and `challenge` decisions were left out of Overview buckets, timelines and
  filters; `by-analyze-method` returned a placeholder.
- **Hosts marked Degraded**: three permanent firewall limitations (notes, not faults) counted as
  coverage warnings, so every host showed the firewall Degraded; only warnings about the host itself
  count now.
- **Runtime Security noise from system services**: systemd's sandbox mounts for unit children such as
  `(fwupdmgr)` (over 13,000 HIGH events a week on one host) and `/proc/1/environ` reads by
  `systemctl`, the environment generator, `needrestart` and `cloud-id` are MEDIUM, tagged
  `unverified-identity` (migration 000111); look-alikes under another parent, non-root mounts, other
  readers and every write stay HIGH.
- **Invitation links** were shown as a bare path (`/invite/<token>`) when no dashboard base URL is
  set; the dashboard now completes them with its own address, and an invitation email is sent only
  with an absolute link.
- **Runtime Security noise**: a credential-dump correlation fired on every daemon that read
  `/etc/passwd`, and the trace program reused a stale file name, so network and credential events
  were escalated as `/etc/shadow` access. A normal SSH login produced about 30 high/critical events;
  it now produces none, while unverified look-alikes stay loud.
- **Trace event loss under bursts** (reader 7× faster; when the ring is nearly full the kernel sheds
  only low-severity events, never sensitive ones, and raises `trace_events_shed`), and a kernel
  WARN on 6.19+/7.0 (path syscalls now attach as kprobes there).
- **Trace event loss in the agent:** the host agent's send queue dropped its oldest events
  whatever their severity, and Runtime Security warned about every loss since the agent started. The
  queue (now up to 32,768 events, memory only during bursts) drops low-severity file/network noise
  first, then low-severity accesses of sensitive files, and keeps process, security, medium+ and
  enforced events; the telemetry loop sends up to four batches per tick in a burst. Loss is reported
  per class for the last hour (the banner clears once the hour is clean), and the agent's
  `trace_events_lost`/`trace_events_shed` reports are always stored (storage sampled most of them
  away before). Reads of `/etc/passwd`, `/etc/group`, `nsswitch.conf` and `authorized_keys`
  are no longer exempt from kernel shedding (ingest drops them anyway): a read loop by any user
  filled the ring and lost 39,242 events on the demo; the same test now loses none.
- **A login during a host agent restart was CRITICAL**: the protected-process set is now filled before
  the trace probes attach, so `sshd` sessions are verified from the first event.
- **The installer did not download security data on agent-only servers** (no control plane binary):
  the host agent had no GeoIP database for geo blocking and the WAF agent no CRS rules. The agent
  binary it installs now fetches its own data.
- **Agents**: bundles refused after an agent was re-created or after migrations rewrote desired
  state; removed route ports stayed open; a long request blocked bundle apply; reconnect backoff
  never reset; the IP jail counted blocks outside its window; failed WAF bundles were never retried;
  firewall resync stopped early after a host agent restart.
- **Tenant fairness**: shared queues, dedupe pools, stream slots and caches are shared fairly per
  owning account and project, so one tenant can no longer drop another's decisions or telemetry,
  fill every stream slot, grow memory without bound, or turn `/ready` red. Host-key prefix
  collisions no longer lock out other hosts; revoked hosts are cut off.
- **API**: FastCGI partial updates no longer wipe other fields; adding an existing member is 409
  `ALREADY_MEMBER`; missing custom rules and trace policies are 404; `users.name` NULL no longer
  breaks the admin user list; login timing no longer reveals registered emails; `LIKE` prefixes in
  the audit filter are escaped.
- **SIEM**: every block/log/challenge verdict is reported once (geo, flood, login protection, path
  rules, GUI rules were missing); custom-rule verdicts carry no body, and credential-like fields in
  body snippets are redacted.
- **Frontend**: the logo is drawn as vector and text, sharp in both themes (the light theme used a grainy PNG); the Email (SMTP) page uses the full width; sign-out respects unsaved-changes guards; partial bulk applies show unsent hosts;
  stale range responses, failed loads shown as zero, and several state leaks across projects.
- Host, agent and label names refuse control and bidi characters; the installer never prints
  server text with escape sequences.

## Changed

- Google Analytics is removed from the dashboard; flags are local; the CSP allows only same-origin
  scripts and connections.
- New `429 STREAM_LIMIT` ceilings for `/waf/stream` and per owning account on every stream.
- A known host agent presenting a wrong or revoked host key is refused; rotating a revoked host's
  key is `409 HOST_REVOKED`.
- The default SMTP host is empty (no email until configured).
- The GitHub release workflow checks out the `uddin-lang` submodule and pins the toolchain.

Security reviews of each part of this release found no cross-tenant read or write; their findings
are fixed apart from a small set of accepted risks.
